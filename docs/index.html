安装说明

  1. 点击「下载 Windows 版」，得到安装包 ClawBuddy_x64-setup.exe。
  2. 双击运行；若提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。
  3. 从开始菜单打开 ClawBuddy，首次启动等待十几秒预热模型与插件。
  4. 在设置里填入 StepFun API Key，即可开始对话。
